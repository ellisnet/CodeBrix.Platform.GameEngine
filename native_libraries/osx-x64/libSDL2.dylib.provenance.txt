libSDL2.dylib -- macOS (Intel x86_64 slice used at runtime)
================================================================================
This binary was DOWNLOADED from the official SDL release page. It was not built

*** THIS IS A UNIVERSAL BINARY AND IS DELIBERATELY DUPLICATED ***
The exact same file is committed at BOTH native_libraries/osx-x64/ and
native_libraries/osx-arm64/. Upstream ships one universal (fat) Mach-O
containing both the x86_64 and arm64 slices, so the two copies are byte-for-byte
identical (same SHA-256).

The duplication is intentional. .NET's real macOS RIDs are osx-x64 and
osx-arm64. Shipping a single copy under a runtimes/osx/native/ folder would rely
on RID-graph fallback, which .NET 8+ de-emphasized by default. Two explicit
copies cost about 3 MB in the package and remove all ambiguity about which file
is selected.

The RUNTIME zip is used deliberately, not SDL2-devel-2.32.10-VC.zip. The runtime
zip contains just the DLL; the devel zip is mostly .lib and .pdb bulk that would
only have to be stripped back out.

Upstream links the C runtime statically, so this DLL imports only OS libraries
(ADVAPI32, GDI32, IMM32, KERNEL32, OLEAUT32, SETUPAPI, SHELL32, USER32, VERSION,
WINMM, ole32) and no vcruntime140.dll / ucrtbase.dll / api-ms-win-crt-*. No
Visual C++ Redistributable is required on the end user's machine. The ARM64
binary we build ourselves matches this by passing SDL_FORCE_STATIC_VCRT=ON.

Upstream GPG-signs the SOURCE tarballs only; the prebuilt binaries are not
signed, so the SHA-256 above is the integrity record for this file.

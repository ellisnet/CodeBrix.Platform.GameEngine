CodeBrix.Platform.GameEngine and CodeBrix.Platform.GameEngine.Host are a
managed, cross-platform 2D / 2.5D game engine for .NET. The engine core is a
vendored port of the open-source Gondwana game engine; the notice below records
that incorporated source and reproduces its license as required.

NuGet package dependencies (SkiaSharp, CodeBrix.SkiaSvg, CodeBrix.Compression,
CodeBrix.Audio, CodeBrix.Json.Extensions, System.Text.Json, and the
Microsoft.Extensions.* packages) are NOT listed here: they are referenced as
packages and ship with their own LICENSE and third-party notices; their source
is not incorporated into these assemblies.

   Version:    v2.5.0 (commit 9da4631d)

   The core library CodeBrix.Platform.GameEngine is a port of the Gondwana
   engine's core project. Source files were copied and adapted: namespaces were
   rewritten from "Gondwana.*" to "CodeBrix.Platform.GameEngine.*" (each ported
   file carries a "//was previously: Gondwana.*" provenance comment on its
   namespace line), the target framework was moved to net10.0, and the following
   dependency substitutions were made during the port:

     * Svg.Skia            -> CodeBrix.SkiaSvg (raw SKSvg / SKPicture surface)
     * SharpZipLib         -> CodeBrix.Compression
     * NAudio              -> CodeBrix.Audio
     * Newtonsoft.Json     -> System.Text.Json + CodeBrix.Json.Extensions
     * SkiaSharp 3.119.2   -> SkiaSharp 4.150.1 (SKFilterQuality -> SKSamplingOptions,
                              SKPaint text API -> SKFont)
     * SkiaSharp.HarfBuzz  -> removed (unused by the core)

   The CodeBrix.Platform.GameEngine.Host library provides CodeBrix.Platform
   integration (render-surface adapters, input adapters, dispatcher); it is
   modeled on Gondwana's Gondwana.Avalonia host project but is fresh code
   written against CodeBrix.Platform.
